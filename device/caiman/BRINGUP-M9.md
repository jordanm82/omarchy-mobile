# Pixel 9 Pro (caiman): Stage 9 — `s2idle` Suspend, Wake Sources, and Sleep Hooks

Goal: verify `s2idle` suspend-to-idle (`SuspendState=freeze`, `MemorySleepMode=s2idle`) on the Pixel 9 Pro (`caiman`, Slot B) with both `alarmtimer` (`s2mpg14-pmic` RTC) and physical Power-key (`gpa4`) wake, clean unload/reload of `BCM4390B1` (`brcmfmac`), and clean post-resume recovery across display, USB NCM, Wi-Fi, Bluetooth, AoC/sensors, and `CS35L41B` speaker protection, while keeping Slot A untouched stock Android (`CP3A.261005.005`).

Stage 8 is complete ([BRINGUP-M8.md](BRINGUP-M8.md)). Path abbreviations follow [NOTES.md](NOTES.md): `R/` = phone hardware runs, `K/` = `linux-omarchy-mobile` (`7.3.0-rc6-omamobile-push1-g646a1459925d`).

## 1. Root Cause & Package Changes

1. **Kernel baseline (`7.3.0-rc6-omamobile-push1-g646a1459925d`).**
   - No kernel patch was required for Stage 9: the `zumapro` base tree already includes `8aaf93ea1` (`ufs@13200000` `"default"` / `"sleep"` pinctrl states, verified in DT as `default sleep`), `rtc0` (`s5m-rtc s2mpg14-rtc`) wake capability (`wakeup=enabled` + `alarmtimer` on `IRQ 52` `GICv3 106 Level s2mpg14-pmic` / `IRQ 53` `rtc-alarm0`), `gpio-keys` `Power` wake on `IRQ 56` (`gpa4 0 Edge Power`), and `WFI`-only `cpuidle` (`none`).
2. **Failure isolation (`BCM4390B1` `brcmfmac`).**
   - Unmodified `systemctl suspend` initially hung inside `PM: suspend entry (s2idle)` (`brcmfmac` logged `Scan abort failed` / `event handler failed (69)` just before sleep entry; `pm_test=devices` and `pm_test=platform` both passed). Unloading `brcmfmac_wcc` + `brcmfmac` allowed `rtcwake -m freeze -s 8` to enter freeze in `43 ms` and wake on `IRQ 52` (`8.8 s`), cleanly resuming UFS (`FAST series_B G_4 L_2` in `22 ms`), USB NCM, Bluetooth (`hci0`), AoC/gyro, and speaker protection.
3. **Userspace (`omamobile-device-caiman` `0.8.0`).**
   - `vendor/systemd/sleep.conf.d/10-omamobile.conf`: adds `SuspendState=freeze` alongside `MemorySleepMode=s2idle`, `AllowHibernation=no`, `AllowHybridSleep=no`, `AllowSuspendThenHibernate=no` (matching `tegu`).
   - `vendor/systemd/system-sleep/omamobile-caiman-wifi`: on `pre`, stops `iwd.service` (if active) and `wpa_supplicant.service` (if active), unloads `brcmfmac_wcc brcmfmac` (under `timeout 20`, skippable via `/etc/omamobile/wifi-keep-across-sleep`), and logs to `/var/log/omamobile/wifi-sleep.log`; on `post`, reloads `modprobe brcmfmac` and restarts `iwd.service` if stopped.
   - `vendor/systemd/system-sleep/omamobile-caiman-nfc` & `omamobile-caiman-cpuidle`: mirror `tegu`'s pre/post hooks pausing `neard.service` (if active) and disabling `cpuidle/state[1-9]*` (no-op when only `WFI` exists) across sleep.
