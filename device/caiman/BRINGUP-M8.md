# Pixel 9 Pro (caiman): Stage 8 — Dual `CS35L41B` Speakers (`omamobile-speaker-protection`), Built-in Microphones, UCM2, and PipeWire

Goal: bring up the Pixel 9 Pro (`caiman`) dual Cirrus Logic `CS35L41B` speaker amplifiers (`spi19`, native CS0 + GPIO CS1 `gpn1-0`) under Cirrus protection firmware (`v0.66.0`) with real read-only F2FS factory calibration from `persist` (`/audio/speaker.cal`) at safe `media` stage (`digital <= 737`, `analog <= 10`, `boost_en=N`, `cirrus,boost-peak-milliamp = <2500>`, `cirrus,dsp-no-hibernate`), expose the AoC sound card (`google,caiman-aoc-snd-card`) with `EP6 playback` and built-in microphones (`0,1,2,-1` on `EP1 capture`) via UCM2 and WirePlumber, and keep Slot A untouched stock Android (`CP3A.261005.005`).

Stage 7 is complete ([BRINGUP-M7.md](BRINGUP-M7.md)). Path abbreviations follow [NOTES.md](NOTES.md): `R/` = local reference captures, `F/` = extracted `CP3A.261005.005` `vendor.img` / `merged_06_49.dts`, `K/` = `linux-omarchy-mobile` (`omamobile-zumapro-caiman-audio`).

## 1. Hardware & Package Scope

1. **Kernel (`omamobile-zumapro-caiman-audio`, `65bbd5123`..`646a14599`).**
   - `65bbd5123` (`clk: samsung: zumapro: Add the HSI0 USI1 clocks`): appends `CLK_{MOUT,GOUT,DOUT}_HSI0_USI1*` (`33..37`) in `include/dt-bindings/clock/google,zumapro.h` (`0x1018`/`0x1818`/`0x211c`/`0x20f4`/`0x20f8`, matching sibling `USI2`/`USI3`).
   - `53c430ecf` (`arm64: dts: exynos: google: zumapro: Add HSI0 USI1 and SPI19`): adds `usi1_hsi0` (`0x111c00c0`, sysreg `0x1018`) and `spi19` (`0x111c0000`, `GIC_SPI 407`).
   - `398367fc1` (`spi: s3c64xx: Keep native CS inactive for GPIO chip selects on manual ports`): prevents `s3c64xx_spi_set_cs()` from falling through to asserting native CS0 (`CS_REG = 0`) when addressing a GPIO chip-select sibling on a `manual_native_cs` controller (configuring `CS_AUTO | NSC_CNT_2 | SIG_INACT` instead so the shifter clocks without colliding on MISO).
   - `646a14599` (`arm64: dts: exynos: google: zumapro-caiman: add speaker amplifiers`): enables `&usi1_hsi0` and `&spi19` (`cs-gpios = <0>, <&gpn1 0 GPIO_ACTIVE_LOW>`), adding fixed always-on `amp_va` (`1.8 V`) and `amp_vp` (`4.2 V`) placeholders plus `amp_top` (`reg = <0>`, `gpp6-3` reset, `gpa5-5` IRQ) and `amp_bottom` (`reg = <1>`, `gph2-1` reset, `gpa7-2` IRQ) at `25 MHz` with `cirrus,boost-cap-microfarad = <4>`, `cirrus,boost-ind-nanohenry = <1000>`, `cirrus,boost-peak-milliamp = <2500>`, `cirrus,gpio2-src-select = <4>`, `cirrus,gpio2-output-enable`, `cirrus,dsp-no-hibernate`, and `cirrus,subsystem-id = "caiman"`.
   - `device/caiman/overlays/aoc-sound.dtso` (`DTB_OVERLAYS="aoc-sound"`): describes `google-aoc-snd-card` (`aoc-card-name = "google,caiman-aoc-snd-card"`), the 53 AoC DAI links (`EP6` + `TDM 0` linking `&amp_top` slots `0/1` RX & `0,2,4,6` TX and `&amp_bottom` slots `1/0` RX & `1,3,5,7` TX), and `clks/sys` `BCLK` bindings while keeping `zumapro-caiman.dts` `dtbs_check`-clean.
   - Built as `7.3.0-rc6-omamobile-push1-g646a1459925d` (`1828` modules, `DTB overlays: aoc-sound`).
2. **Firmware extractor (`tools/extract-vendor-firmware -d caiman`).**
   - Extracts `cs35l41-dsp1-spk-prot.{wmfw,bin}` and `R-cs35l41-dsp1-spk-prot.bin` as `cirrus/cs35l41-dsp1-spk-prot-caiman.{wmfw,-top.bin,-bottom.bin}` (`34200` / `5076` / `5032` bytes) and verifies WMFW Halo v4, `FIRMWARE_HALO_CSPL`, `CAL_CHECKSUM`, and distinct `WMDR` coefficients.
3. **Userspace (`omamobile-audio` `0.5.19` + `omamobile-device-caiman` `0.7.0`).**
   - `packages/omamobile-audio/lib/persist_f2fs.py`: read-only pure-Python F2FS parser (`0xf2f52010`, CP NAT bitmap, `F2FS_EXTRA_ATTR`/`F2FS_INLINE_XATTR`, inline/block dentries & data) so `omamobile-speaker-protection` reads `/audio/speaker.cal` from `caiman`'s unmounted `f2fs` `persist` (`/dev/sda1`) without mounting it (`debugfs` remains primary for `ext4`).
   - `omamobile-speaker-protection.service` adds `ConditionPathExists=|/sys/bus/platform/devices/154b0000.aoc`; `ucm2/conf.d/aoc-snd-card/google,caiman-aoc-snd-card.conf` + `ucm2/Google/caiman/HiFi.conf` configure `TDM_0` `S32_LE` / `SR_48K`, `TDM_0_RX Mixer EP6`, and `BUILDIN MIC ID CAPTURE LIST 0,1,2,-1` (`MIC DC Blocker 1`, `MIC Record Soft Gain (dB) 22`, `EP1 TX Mixer INTERNAL_MIC_TX 1`); `wireplumber/56-omamobile-caiman-aoc.conf` sets `api.alsa.soft-mixer = true`, `disable-mmap = true`, `960 x 4` frames on `google,caiman-aoc-snd-card`.
   - `omamobile-device-caiman` `0.7.0` depends on `omamobile-audio>=0.5.19`, enables `omamobile-speaker-protection.service` via `multi-user.target.wants/`, and syncs `DTB_OVERLAYS="aoc-sound"` in `device.conf`.
